# TLD Technologies — Personal Landing Page

## Project Title & Description

Personal landing page to offer freelance services — minimalist design,
conversion-focused layout and accessible interactions.

## Built With

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- PostCSS
- Vercel (for deploy)

## Key Features

- Clean, responsive one-page layout
- Conversion-focused Hero and CTA sections
- Reusable components under `app/` and `components/`
- Accessibility: visible focus states and reduced-motion support
- Performance: font loading via `next/font` and Next.js optimizations

## Getting Started (Local Installation)

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
